# 脆皮捏捏模拟器

把小红书上很火的「脆皮捏捏」搬进浏览器：按住、搓、捏，听脆皮「咔嚓」一声裂开，掉一桌渣，再接着揉里面软乎乎的内芯。

零依赖、无构建：原生 ES Modules + Canvas 2D + WebAudio，手机触屏优先，桌面鼠标也能玩。

## 怎么跑

ES Modules 需要走 http，随便起一个静态服务器即可：

```bash
python3 -m http.server 5173
```

然后打开 <http://localhost:5173/>。整个仓库就是一个静态站点，也可以直接挂到 GitHub Pages。

## 怎么玩

- **点一下**：指尖下那块脆皮立刻裂开，裂纹沿着相邻碎片一路传出去
- **按住**：受力范围慢慢变大，周围的脆皮跟着碎
- **搓 / 拖**：把已经裂开的碎片剥下来，掉到桌上
- **脆皮剥光后**：内芯可以一直捏，按下去有鼓包和指印
- **点桌上的碎片**：还能再碾碎一遍
- 「换一款」里可以选造型，也可以自由搭配脆皮厚度和内芯

| 脆皮 | 特点 |
| --- | --- |
| 薄脆 | 碎片小而多，一碰就连锁开裂，声音又尖又脆 |
| 标准 | 折中 |
| 厚蜡 | 碎片大块，要多按几下，声音更闷更厚 |

| 内芯 | 特点 |
| --- | --- |
| 慢回弹 | 捏出的形变和指印约 1 秒慢慢恢复 |
| 黏土 | 一次性：捏成什么样就留什么样 |
| 爆浆 | Q 弹抖动，里面有亮片，带「咕叽」水声 |

## 实现要点

| 文件 | 内容 |
| --- | --- |
| `src/shapes.js` | 用 SDF（圆 / 椭圆 / 圆角盒 / 胶囊 + 平滑并集）描出造型轮廓；款式、脆皮、内芯的参数表；把完整脆皮画成一张贴图 |
| `src/fracture.js` | 预先把脆皮切成 Voronoi 碎片并记录邻接关系，共享边加确定性锯齿，裂缝两侧严丝合缝 |
| `src/softbody.js` | 内芯软体：轮廓粒子 + 内部点阵，PBD 积分；被完好脆皮盖住的粒子会被「钉住」，所以脆皮没碎之前捏不动 |
| `src/round.js` | 一局的全部状态：按压伤害、连锁开裂队列、碎片脱落与落地、渣渣、指印、通关判定 |
| `src/render.js` | 绘制：内芯（渐变 + 指印 + 表情）、完好脆皮层、裂开的碎片精灵、桌面碎片 |
| `src/audio.js` | 全部音效实时合成，无音频文件：咔嚓 = 瞬态 click + 高频共振模态 + 砂砾噪声 + 微小二次碎裂 |
| `src/main.js` | 画布、输入（多指）、HUD、选款面板、主循环 |

想调手感，改 `src/shapes.js` 里的 `SHELL_TYPES`（碎片数、韧性、裂纹传播）和 `CORE_TYPES`（回弹频率、阻尼、鼓包幅度、指印恢复时间）。
加新款式就是往 `PRESETS` 里加一项：一个 SDF、两组颜色、一个可选的花纹函数。
