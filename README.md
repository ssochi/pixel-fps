# 脆皮捏捏模拟器

把小红书上很火的「脆皮捏捏」搬进浏览器，3D 的：一只蜡壳包着软膏体内馅的面包（或者巧克力、大福）放在盘子里，按住它、捏它、搓它，蜡壳「咔嚓」裂开、崩飞、掉一盘子，里面的内馅被捏出坑、挤得鼓起来、从裂缝里冒出来，而且**捏成什么样就留什么样，不回弹**。

原生 ES Modules + [Three.js](https://threejs.org/)（r128，从 cdnjs 加载）+ WebAudio，无构建步骤。手机触屏优先，桌面鼠标也能玩。

## 怎么跑

ES Modules 需要走 http，随便起一个静态服务器即可：

```bash
python3 -m http.server 5173
```

然后打开 <http://localhost:5173/>。整个仓库就是一个静态站点，也可以直接挂到 GitHub Pages。

## 怎么玩

- **点一下**：指尖下那块脆皮当场裂开，裂纹往周围传
- **按住**：越按越深，坑留在那儿不回弹；被挤走的内馅在坑边堆起来，整只变扁、往四周摊开，蜡壳被掰弯到极限就一片片裂开
- **裂了但还贴着的壳下面**：内馅没处去，会从裂缝里挤出来鼓成一道道
- **两指对着捏**：从两侧往中间挤，蜡壳成片崩飞
- **多捏几下**：越捏越扁，最后揉成一坨
- **搓**：把裂开但还粘着的碎片搓下来
- **蜡壳掉光后**：内馅可以一直揉
- **点盘子里的碎片**：碾成渣
- **拖空白处**：转视角
- 「换一款」里选造型，也可以自由搭配脆皮厚度和内芯

款式：十字餐包、菠萝包、牛奶棒、生巧砖、坚果巧克力球、草莓大福。

| 脆皮 | 特点 |
| --- | --- |
| 薄脆 | 碎片小而多，稍微一弯就裂，声音又尖又脆 |
| 标准 | 折中 |
| 厚蜡 | 大块，要捏得更狠才裂，声音更闷更厚 |

| 内馅 | 特点 |
| --- | --- |
| 凡士林（默认） | 软膏体：不回弹，按得深、摊得开，表面油亮，会从裂缝里挤出来 |
| 黏土 | 同样不回弹，但更硬：坑浅、不爆浆、哑光 |
| 慢回弹 | 工厂量产的那种 PU 芯裹蜡：捏出的坑约 1 秒慢慢弹回来 |

真实的脆皮捏捏是大豆蜡 / 蜂蜡做壳。手作款的内馅是凡士林、黏土这类软膏体，所以是一次性的；会回弹的是在慢回弹 PU 玩具外面裹蜡的量产款。

## 实现要点

| 文件 | 内容 |
| --- | --- |
| `src/foods.js` | 款式表：每款是一个 3D SDF 造型，加表面细节（刀口、格纹、坚果粒）、烤色函数、内芯颜色；脆皮和内芯的参数表 |
| `src/geo.js` | 测地球按 SDF 鼓成食物造型；多源 Dijkstra 把表面切成连通的脆皮碎片，再把碎片边界拉直 |
| `src/squishy.js` | 一只捏捏的全部状态。内馅（膏体）：按压只往前走不回头，每帧按网格体积做守恒修正（按进去多少体积，周围就鼓出多少），手指经过处做拉普拉斯抹平，并限制不能按穿、不能摊出盘子；裂缝线上的顶点在受压时向外鼓，就是爆浆。蜡壳：碎片被掰弯超过极限就裂，裂后作为刚性薄片跟着内馅走，再被继续挤或被搓就脱落成刚体，落盘、躺平 |
| `src/stage.js` | Three.js 场景：盘子、桌面、主灯和阴影、摄影棚式环境反光、蜡粉、镜头轻震、环绕相机 |
| `src/audio.js` | 全部音效实时合成，无音频文件：咔嚓 = 瞬态 click + 高频共振模态 + 砂砾噪声 + 微小二次碎裂 |
| `src/main.js` | 输入（多指）、HUD、选款面板、主循环 |

想调手感，改 `src/foods.js` 里的 `SHELL_TYPES`（碎片数、能承受的弯折、裂纹传播）和 `CORE_TYPES`（回不回弹、按多深、陷多快、爆不爆浆），以及 `src/squishy.js` 里 `stepCore` 的按压深度、凹坑半径和压扁系数。
加新款式就是往 `FOODS` 里加一项：一个 SDF、一个表面细节函数、一个上色函数。
